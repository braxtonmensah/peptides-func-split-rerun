# signals

Outside signals for this repository, logged by hand on the day they are seen (US Eastern):
forks with a successful run of the `rerun` workflow in their own Actions tab, stars from accounts
other than the owner, and citations of the release or of a Peptides-func result on the corrected
split (Google Scholar, GitHub code search for "peptides-func-split-rerun"). One JSON line per signal
in `ledger.jsonl`: {"date", "kind", "who", "url", "note"}.
